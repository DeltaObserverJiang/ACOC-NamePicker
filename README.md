# A.C.O.C. 点名系统

一套课堂随机点名工具，由点名器与配置器两部分组成。

`index.html` 是点名器本体：单文件、零构建、双击即用，也可以直接放到任意静态
托管上。名单与全部逻辑都在这一个文件里；除了向 Google Fonts 取 Oswald 与
Noto Sans SC 这两款字体，运行时不联网，也不向外部发送任何内容。字体取不到就
落回系统无衬线字体，功能不受影响。

`configurator/` 是配套的 Windows 配置器：勾选所需功能、录入名单，即可生成一份
只包含这些功能的点名器。生成的成品同样是单文件双击即用。

## 配置器

| 分组 | 选项 |
| --- | --- |
| 抽取模式 | 不重复、连续抽取、轮字抽取 |
| 设置菜单 | 概率修改、顺位设定、统计数据 |
| 界面主题 | 暗境节点（AT）、经典节点（CLASSIC） |
| 名单与数据 | 名单装载节点、高级数据管理 |
| 实验性 | 实验性功能、故障跳跃 |

全随机模式为基础功能，始终保留。关闭「名单装载节点」后，点名器启动时直接
采用班级列表首位的班级。

一个点名器可以容纳多个班级。名单页左侧为班级列表，支持新建、重命名、排序与
删除，列表首位即默认班级。

左侧第三栏「点名器更新」是一段纯粹的输入-输出：选一份旧版点名器，直接得到一份
最新版。名单从文件里读出来，其余一律按当前模板重写，中间不用做别的。班级名照抄
原文，所以本机累积的统计、概率与顺位会自然接上，不必手工搬运。旁边的「只提取名单」
把名单放回工作区，想改名单或加班级时用它。

## 名单

支持 Excel（`.xlsx` / `.xlsm`）与 CSV，表格形态不限：

- 仅姓名一列
- 学号与姓名两列
- 上述任一种，外加一行「学号 / 姓名」表头
- 表格前带有空行或说明行

无法识别时会明确指出是哪一项不符。没有表格也可以，配置器内可直接增删改。

已经导出过的成品也可以反过来读回配置器：名单页的「从点名器导入」直接解析该
HTML 里内嵌的班级与名单，把整份工作区还原出来，导出时默认写回同一个文件。
此前经由 v0.1 生成的页面同样认得。

导入不要求文件由本配置器生成：先认标题与页面里的点名器特征，确认这确实是点名器，
再依次找内嵌的班级预设（`CLASS_PRESETS`）、班级常量、预设装载调用
（`initSystemData`）与脚本里的名单数组，最后才退到页面里的表格与列表。
v0.1 起各版本的成品都能读出班级与名单。

点名器运行时的 Excel 导入同样可用，且**不依赖任何外部库或网络**——xlsx 本质上
是 ZIP 容器内的压缩 XML，读取逻辑已内嵌在文件里。

## 本机存档

点名器会把每班的统计数据、概率权重与顺位设定记在浏览器本地，按班级名分开保存。
下次装载同一个班级时自动接着上次，不必从头累积。存档仅保存在本机，不会上传；
设置菜单中可随时清除，最多保留最近八个班级。

存档以班级名为键，所以换版本时只要班级名不变，统计就自动续上。旧版用过的
「A2班 (预设)」这类带后缀的名字同样在识别范围内，装载时会归并到当前班级名下，
不会留下两份记录。

## 构建

仅支持 Windows，使用 CMake 与 MinGW-w64（UCRT）：

```sh
cmake -S configurator -B configurator/build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build configurator/build
```

安装包由 `configurator/installer/` 以同一套工具链构建，产物为
`ACOCConfiguratorSetup.exe`，安装到当前用户目录，无需管理员权限，并兼作卸载程序。
若点名器正在运行，安装程序会在确认页说明，并在继续前先请其退出。

修改 `index.html` 后需重新生成模板：

```sh
python configurator/tools/make_template.py
```

模板工具按行号定位各个功能区块，因此它自带一份边界自检：`index.html` 的行数或边界行
一变，就直接报错并指出是哪一条对不上，而不是默默生成一份裁错的模板。行号整体位移时
先用 `tools/remap_template_lines.py` 重新映射。

成品与 `index.html` 的一致性可以随时复核：

```sh
configurator/tools/update_test.cpp    # 见 tools/ 下的编译方式：
# c++ -std=c++17 -Isrc -o update_test tools/update_test.cpp \
#     src/generator.cpp src/importer.cpp src/roster.cpp src/zipfile.cpp
# ./update_test configurator/res/template.html index.html <输出目录> [其它旧版点名器.html ...]
```

它把各历史版本的点名器逐个喂给导入器、再生成最新版；输入是当前版本时，要求生成结果
与 `index.html` 逐字节一致。

## 运行环境

Windows 7 SP1 及以上。程序依赖系统通用 C 运行库（`api-ms-win-crt-*.dll`），
Windows 10 与 11 已内置；Windows 7 与 8.1 需先安装
[KB2999226](https://www.microsoft.com/en-us/download/details.aspx?id=49093)，安装后重启。

## 目录

```
index.html              点名器本体
configurator/
  src/                  配置器源码
  res/                  图标、清单、模板
  installer/            安装程序
  tools/                构建与测试脚本
  _test/                测试夹具与界面自动化
```
